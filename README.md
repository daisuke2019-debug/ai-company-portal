# ai-company-portal

AI Company用の公開リポジトリ。GitHub Pages で公開されるのは `site/` フォルダだけ。

| フォルダ | 内容 | URL |
|---|---|---|
| `site/portal/` | Visual Portal（全AI社員ポータル） | https://daisuke2019-debug.github.io/ai-company-portal/portal/ |
| `site/board/` | 取締役会資料 | https://daisuke2019-debug.github.io/ai-company-portal/board/summary.html |
| `site/note/` | Note記事プレビュー・共有ボードのデモ | https://daisuke2019-debug.github.io/ai-company-portal/note/first-post.html |
| `site/links.html` | 全サイトのURL一覧 | https://daisuke2019-debug.github.io/ai-company-portal/links.html |
| `site/index.html`・`site/public_html/` | 古いURL用の転送ページ（編集しない） | — |

仕事用ツール（SRP施策ポータル・店舗マスタミスポータル・画像注釈スタジオ）は `work-portal` リポジトリで管理している。

## ルール
- 公開するファイルは必ず `site/` の中に置く。
- 音声・請求データ・作業用ファイルは `site/` に入れない（OneDrive の AI Company フォルダに置く）。
