# AI Company 統合ダッシュボード ＆ DCM SRP施策ポータル

ボーダー共有・店舗巡回FSM用 現場ヒアリング＆報告マスタ入力ポータルWebアプリケーションです。

## 🌟 主な機能
- 📊 **AI Company 統合ダッシュボード**: KPIサマリー・代理店進捗ステータス
- 📋 **ワンクリックコピー機能**: SRP施策 / 販売コンテスト / FFF8還元施策 コメントテンプレート
- 🏢 **全21代理店 早見表**: リアルタイム検索・フィルタリング・カラー表示
- 🌙 **ダーク/ライトモード切替** & **マルチデバイス対応 (レスポンシブ)**

## 🚀 GitHub Pages 公開手順
1. GitHub で新しいリポジトリ（例: `ai-company-portal`）を作成します。
2. このフォルダーのファイル（`index.html`）をリポジトリにプッシュ（またはWebからドラッグ＆ドロップ）します。
3. リポジトリの **Settings** ＞ **Pages** ＞ **Branch: main** を選択して Save します。
4. 数秒で `https://<ユーザー名>.github.io/<リポジトリ名>/` にてWebサイトが無料公開されます！
